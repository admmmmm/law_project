# 证据0-4：广东省公安厅“百日信息会战”工作要求节录

- 证据类型：上级机关工作要求、职责依据
- 案情时间：2024年6月至2024年8月
- 对应案情：百日信息会战期间，杨周武未督促如实上报舞王俱乐部无证无照经营和重大隐患
- 证明事项：证明基层派出所在专项工作中负有排查、上报、整治重点治安隐患场所的职责。

## 工作要求节录

广东省公安厅“百日信息会战”要求，各地公安机关应当对辖区娱乐服务场所、人员密集场所和治安复杂区域开展集中排查，对发现的无证无照经营、消防隐患、涉黄涉毒、打架斗殴等重点问题，应当如实登记、及时上报并推动整改。

对反复发生治安警情、存在重大安全隐患的歌舞娱乐场所，辖区派出所应当落实责任民警，形成检查、报告、整改、复查的工作闭环。

## 与案情梳理的关系

- 对应“2024年6月至8月”百日信息会战节点。
- 作为职责来源材料，用于证明杨周武对舞王俱乐部隐患排查、报告和处置负有管理责任。
- 需要结合证据0-2、证据0-3、证据5-2证明其实际知情和未履职。
