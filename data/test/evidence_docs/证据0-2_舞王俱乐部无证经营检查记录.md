# 证据0-2：舞王俱乐部无证经营检查记录

## 检查记录节录

2023年9月以后，同乐派出所责任区民警在对龙岗区三和村同富路18号舞王俱乐部进行检查时发现，该场所未能出示有效《消防许可证》和《娱乐经营许可证》。

现场负责人提供的营业执照复印件显示名称为“舞王俱乐部”，登记期限至2023年08月30日，已超过有效期限。民警还发现，该场所实际经营布局、出入口、消防通道和人员容量与登记材料及安全要求不符。

责任区民警将上述情况以口头和书面方式报告同乐派出所所长杨周武，建议依法责令停业整顿，并提请相关部门核查取缔。

## 警情记录节录

2023年10月以后，同乐派出所多次接报舞王俱乐部存在超时经营、人员拥挤、酒后滋事、涉黄涉毒线索和治安纠纷。部分警情处置后，责任区民警再次向所领导反映该场所存在重大治安和消防隐患。

杨周武未督促责任区民警持续跟踪整改，也未组织依法取缔或者责令停业整顿。
