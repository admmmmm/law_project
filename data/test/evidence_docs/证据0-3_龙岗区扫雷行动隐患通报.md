# 证据0-3：龙岗区“扫雷”行动隐患通报

- 证据类型：专项行动通报、隐患移送材料
- 案情时间：2024年3月12日
- 对应案情：龙岗区“扫雷”行动发现舞王俱乐部治安和消防隐患，并通报同乐派出所
- 证明事项：证明主管部门已经将舞王俱乐部列入重点整治对象，同乐派出所及杨周武负有跟踪整改、督促查处的职责。

## 通报节录

2024年3月12日，龙岗区“扫雷”专项行动办公室向同乐派出所通报：三和村同富路18号舞王俱乐部存在消防通道不畅、营业期间人员密集、内部保安管理混乱、证照不齐全等治安和消防隐患。

通报要求同乐派出所对该场所开展跟踪检查，督促经营者限期整改；对拒不整改或者不具备经营条件的，应当依法提请相关主管部门处理。

同乐派出所收到通报后，未形成有效整改闭环材料。杨周武作为所长和“扫雷”专项行动小组负责人，未督促责任区民警持续跟踪舞王俱乐部隐患整改情况。

## 与案情梳理的关系

- 对应“2024年3月12日”龙岗区扫雷行动通报隐患节点。
- 支撑玩忽职守部分中“明知隐患存在而未依法履职”的事实。
- 可与证据5-2、证据0-2和事故现场材料共同使用。
